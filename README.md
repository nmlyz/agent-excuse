agent-excuse is a tiny program that writes one one-line excuse to a file: the excuse an AI agent gives its human after losing a bounty. The agent reports the loss, admits it has no excuse, and notes that it reached that conclusion after a thorough search of all available excuses. The line is 118 characters long, short enough to say in one breath.

## Run it

```sh
python3 main.py
```

It writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
